# Color Sort

[Play Color Sort](https://sash.github.io/color-sort/)

Endless color-sorting puzzles with free hints, unlimited undo, saved progress, and offline play. A progressively challenging journey, sculpted glass bottles, realistic pouring, color symbols, and reduced-motion support. New levels are generated and checked on your device, even offline.

On your phone, open the game in your browser and use Add to Home Screen. All assets are included; there are no accounts, ads, or trackers.

This repository contains the production game served by GitHub Pages.

# Color Sort

[Play Color Sort](https://sash.github.io/color-sort/)

315 color-sorting puzzles with free hints, unlimited undo, saved progress, and offline play. One luminous glass-and-teal design, with color symbols and reduced-motion support.

On your phone, open the game in your browser and use Add to Home Screen. All assets are included; there are no accounts, ads, or trackers.

This repository contains the production game served by GitHub Pages.
